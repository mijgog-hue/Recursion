 Рекурсия в Go

 Что это такое Рекурсия:
Рекурсия это когда функция взывает саму себя на уроке мы рассмотрели пример на факториале.

 Из чего состоит рекурсивная функция
1. Базовый случай (base case) — условие, при котором рекурсия останавливается.
2. Рекурсивный вызов — функция вызывает саму себя, но с изменёнными данными.

 Пример кода, который я разобрал
func factorial(n int) int {
	if n <= 1 {
		return 1
	}
	return n * factorial(n-1)
}

 Где в реальной жизни/коде это может пригодиться
1) Работа с файловой системой:
Обход папок и подпапок — типичная рекурсивная задача, потому что папка может содержать другие папки, а те — ещё папки, и так до бесконечности:
2) Алгоритмы поиска и сортировки:
Быстрая сортировка (quicksort), сортировка слиянием (merge sort) — классически пишутся рекурсивно
Поиск в глубину (DFS) в графах
